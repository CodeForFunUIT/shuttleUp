## Known Issues / Tech Debt

- **Freezed `sealed class`**: All `@freezed` classes need `sealed` keyword (Freezed v3)
- **Duplicate DI files**: Both `injection.dart` and `injection_container.dart` exist
- **Mock data in BLoC**: `SessionBloc` has hardcoded mock sessions, needs API
- **No repository layer**: BLoC calls mock data directly, no repository pattern
- **Deprecation warnings**: `withOpacity()`, `printTime`, `background` parameter
- **Widget test broken**: Default Flutter test references wrong class name
