# Migrate to go_router_builder — Type-Safe Generated Routes

## Problem

Current `routes.dart` uses unsafe `state.extra as SessionModel` casting:

```dart
GoRoute(
  path: '/sessions/:id',
  builder: (context, state) {
    final session = state.extra as SessionModel; // ❌ unsafe cast, no compile-time check
    return SessionDetailPage(session: session);
  },
),
```

**Issues:**
- Runtime crash if `extra` is null or wrong type
- No IDE autocompletion for navigation params
- Manual string-based paths — typos cause silent failures
- Route params manually extracted — boilerplate

## Solution: `go_router_builder`

Code-generates type-safe route classes from `GoRouteData` annotations. Params auto-injected.

### How It Works

```dart
// BEFORE — manual, unsafe
context.push('/sessions/$id', extra: session);

// AFTER — type-safe, auto-generated
SessionDetailRoute($extra: session).push(context);
```

### Implementation Plan

#### 1. Add dev dependency

```yaml
# pubspec.yaml
dev_dependencies:
  go_router_builder: ^2.7.1  # latest compatible with go_router ^17
```

#### 2. Create route classes in `routes.dart`

```dart
import 'package:go_router/go_router.dart';
import 'package:flutter/material.dart';
// ... page imports ...

part 'routes.g.dart';  // generated file

@TypedGoRoute<SessionListRoute>(
  path: '/',
  routes: [
    TypedGoRoute<SessionDetailRoute>(
      path: 'sessions/:id',
      routes: [
        TypedGoRoute<GuestBookingRoute>(path: 'book'),
      ],
    ),
  ],
)
class SessionListRoute extends GoRouteData {
  const SessionListRoute();
  @override
  Widget build(BuildContext context, GoRouterState state) =>
      const SessionListPage();
}

class SessionDetailRoute extends GoRouteData {
  final String id;
  final SessionModel $extra;  // auto-injected via extra
  const SessionDetailRoute({required this.id, required this.$extra});
  @override
  Widget build(BuildContext context, GoRouterState state) =>
      SessionDetailPage(session: $extra);
}

class GuestBookingRoute extends GoRouteData {
  final String id;
  final SessionModel $extra;
  const GuestBookingRoute({required this.id, required this.$extra});
  @override
  Widget build(BuildContext context, GoRouterState state) =>
      GuestBookingPage(session: $extra);
}

@TypedGoRoute<LoginRoute>(path: '/login')
class LoginRoute extends GoRouteData {
  const LoginRoute();
  @override
  Widget build(BuildContext context, GoRouterState state) => const AuthPage();
}

@TypedGoRoute<DashboardRoute>(path: '/dashboard')
class DashboardRoute extends GoRouteData {
  const DashboardRoute();
  @override
  Widget build(BuildContext context, GoRouterState state) =>
      const DashboardPage();
}

@TypedGoRoute<ProfileRoute>(path: '/profile')
class ProfileRoute extends GoRouteData {
  const ProfileRoute();
  @override
  Widget build(BuildContext context, GoRouterState state) =>
      const ProfilePage();
}

// Router config — uses generated $appRoutes
final GoRouter appRouter = GoRouter(
  initialLocation: const SessionListRoute().location,
  routes: $appRoutes,
);
```

#### 3. Generate code

```bash
dart run build_runner build --delete-conflicting-outputs
```

#### 4. Update navigation calls across pages

```dart
// BEFORE
context.push('/sessions/${session.id}', extra: session);

// AFTER
SessionDetailRoute(id: session.id, $extra: session).push(context);
```

## Key Points

| Aspect | Detail |
|--------|--------|
| `$extra` field | Special name — go_router_builder passes it via `GoRouterState.extra` |
| Path params (`:id`) | Must match constructor field name exactly |
| Query params | Optional fields not in path become query params automatically |
| Nested routes | Define via `routes:` in `@TypedGoRoute` annotation |
| Generated output | `routes.g.dart` — contains `$appRoutes` list + `.location` getters |

## Risks

| Risk | Mitigation |
|------|-----------|
| `$extra` lost on deep link / browser | Mobile-only app — not a concern |
| Version compat go_router ↔ builder | Both maintained by Flutter team, check pub.dev |
| Migration effort | 6 routes, small — ~30 min total |
